# codersHub

CODER'S HUB is a frontend-only coding resource project.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome (CDN)

No framework, build tool, package manager, or backend has been introduced.

## Pages

- `index.html` — landing page
- `menu.html` — main menu and feature overview
- `learningpath.html` — searchable learning paths and roadmap modal
- `snippets.html` — searchable/filterable code snippet library
- `submit.html` — snippet submission form
- `loginpage.html` — login/register UI

## Responsive rewrite

The codebase has been rewritten while keeping the existing tech stack and user-facing feature set. Layouts now adapt to phone, tablet, desktop, and large-screen widths using fluid sizing, CSS Grid/Flexbox, responsive breakpoints, and safer overflow handling.

The project remains frontend-only; no backend/authentication/database functionality has been introduced.
